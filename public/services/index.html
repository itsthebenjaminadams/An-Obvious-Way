01 / SUPPORT

Tech support

From $49 diagnostic

For a Windows PC that keeps misbehaving, a new device that needs setting up, or Wi-Fi that drops in the wrong room.

What we can scope: Reproduce the issue, narrow down the likely cause, and identify the next repair or configuration step. Ask about secure remote-access setup if you need to reach a device away from home.

What to share: Device model, Windows version, when the problem started, and the exact error if you have it.
